# 2026-09-09 複数バブルを標準にして暗号化版と比較する

## 依頼と決定

ユーザーの指定に従い、[Bubble Multiの公開ソース](https://henkaku-ui.vercel.app/bubble-multi)を使って標準イントロを差し替える。追加指定により暗号化版もGitHubに参考用として残し、画面で切り替えて比較できるようにする。参加者が入口から既存の体験画面へ進む導線を検討するデモブランチの変更とする。

- 8つの泡の浮遊・融合・分離と、ポインタに追従する泡の尾を参照元の実装に基づいて構成する。
- 複数バブル版は本文を常に通常表示し、リンクから対応画面へフェード遷移できるようにする。空白クリックで暗号化しない。
- 添付ロゴ由来の形、既存の機能名、スマートフォンのレイアウトを維持する。参照元の表示モード切替と、動きを減らす設定・Canvas 2Dへのフォールバックを保持する。
- イントロ左下の「複数の泡」「暗号化＋泡」で比較する。切替前の描画を停止し、iframeを作り直す。新規表示の標準は複数バブルとする。
- ホーム、Journey、Community、Passport、Podcast紹介は維持する。ホーム末尾のThresholdの文字演出も独立した実装として維持する。

## アーカイブと生成

暗号化版の原本とレイアウトを`assets/reference/gateway/archive/encrypted-intro/`へ移す。切替直前の基準コミットは`023859567abeb011e501a8cecdb67ee684734e83`。原本のバイト一致を確認してから移動する。

`build-gateway.mjs`は個別のアダプターを呼び、新しい`bubble-multi.html`と比較用の`intro.html`を生成する。暗号化版の描画モジュールと元のライセンス表記を保持する。アーカイブのREADMEに構成と復元の方針を記録する。

切替前の全10ファイルをまとめたローカルZIPも保持する。こちらはGitとVercelの対象外とし、原本の参考公開と区別する。
