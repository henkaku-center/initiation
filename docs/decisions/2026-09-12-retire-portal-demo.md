# 2026-09-12 ポータルの模擬アプリを廃止する

## 決定

通常アプリに接続した画面・演出を唯一の参加フローとして維持する。依頼者の「本番に移行していればDemoの方は不要」という指示に従い、`/demo` の模擬画面、ウォレット・回答・申請・審査・報酬を模擬するコードとストア、「デモ操作」を削除する。

`dev:demo` / `build:demo` と `HENKAKU_DEMO_ONLY` による分岐、デモ用Proxy、CIのデモbuildも削除する。通常版のProviders・認証API・Server Actionsは常に利用できる構成にする。既存の認証・認可とサーバーの完走条件は変更しない。

## 残すもの

- 通常画面が使うGateway、ダイアログ、Communityカード、CSSを `components/portal/` へ移す。模擬状態の引数・操作は除く。
- 画像・音源・出典・ライセンスを保持する。`public/demo-assets/` は取り込み時からの素材URLとして残るが、別のアプリや保存経路ではない。
- HomeとイントロのHTMLは編集元から通常URLを持つ一組だけを生成する。FREQUENCYとPODCAST、5問・再編集、テーマ・イントロの表示設定を保つ。
- 旧 `/demo` は `/` へ308リダイレクトし、フラグメントを通常Homeの既存マッピングで解決する。`/demo#journey` は `/initiation` へ進む。
- 旧 `henkaku.portal-demo.v1` は読み書き・自動移行しない。ブラウザ内に残っていても認証・回答・完走・申請の根拠にならない。

## 検証と公開

削除前に表示・ビルド契約の失敗テストを確認する。通常build、型チェック、lint、unit、ローカルSupabase統合、5画面・旧URL・配色・キーボード・実認証フローを検証する。廃止したシミュレーター固有のテストは削除し、現在のアプリに対するテストを残す。

この変更の前提はコードの接続完了であり、公開環境へのデプロイ完了ではない。公開には別の許可と実環境での確認が必要。noindexは維持し、ロールバックは記録した以前のデプロイへ戻す。追加migration、DB削除、デモ進捗の移行は不要。

以前の[通常アプリ接続](./2026-09-12-portal-app-integration.md)と[デモの決定](./2026-09-09-portal-experience-demo.md)のうち、別の模擬アプリを維持する方針をこの決定で置き換える。
