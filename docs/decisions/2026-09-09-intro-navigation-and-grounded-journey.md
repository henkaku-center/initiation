# 2026-09-09 全画面イントロのリンク遷移と旅人の接地

## 依頼と決定

ユーザーの追加指定に従い、Liquidをトップページとは別の全画面イントロにする。空白のクリックは暗号化／復号を繰り返し、復号後のハイパーリンクはフェードして対応するHome / Setup / Initiation / Community / Passportへ移動する。調整パネルと再生機能を保持する。PUBLIC GATEWAYとBEGIN INITIATIONが重なる配置を防ぎ、リンク先の重複を整理する。

- 参照元の遅延破棄が新しいrendererを破棄する競合を修正。各再生の番号で非同期キャプチャ・RAFを無効化し、終了時に両rendererを破棄する。
- 親画面が同一オリジン・iframe送信元・遷移先を検証してフェードを実行する。スキップとトップページからの再生を用意し、初回表示状態はタブ内に保存する。
- トップページはCommunity Pulse / Voices / Frequency / Thresholdの4章を維持し、独立したヘッダーとメニューを追加する。
- 生成した旅人、足元の影、背景を同じシーン座標に配置する。質問フォームとシーンを分け、足を支点に小さな呼吸・重心移動を付ける。動きを減らす設定では静止する。
- デモ隔離・ブラウザ内の仮データ・音声の手動再生を維持する。

## 検証と公開

最新のユーザー指定に従い、検証はブラウザのレイアウト確認に限定する。単体・統合テストや独立したlint・型チェックは実施しない。幅360 / 390 / 768 / 1440pxと横長画面について、イントロ、トップページ、Journey、Community、Passportのはみ出し・重なりを確認する。テスト関数はtests/layout/portal-layout.mjsに保存する。
