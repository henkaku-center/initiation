# 2026-09-09 指定ソースを基準にトップページを忠実に構成する

## 依頼

ユーザーが`/liquid`のコードと調整項目、`/gateway-v1-claude`の残りのデザインを忠実に実装し、添付ロゴと新しいCommunity/Passport画像へ差し替え、テストせずデプロイするよう明示した。

## 決定

- 前回の独自アレンジをトップページから外し、指定された公開HTML/CSS/JSをローカルへ収録して組み合わせる。
- 原作のスクロール量・画面高・sticky・描画スナップショットの前提を維持するため、同一オリジンの独立した文書をトップページ内に表示する。別アプリや別の公開先は作らない。
- Liquidの解読19スライダー、色設定、Bubble 12スライダー、イントロ再生、折りたたみタブを維持する。ソース内の「埋め込み時は調整UIを隠す」処理だけは、この用途に合わないため適用しない。
- ロゴは添付80px画像の形状をSVG化する。機能名とリンク先は既存のSetup / Initiation / Community / Check-in / Allowlist / HENKAKU / Passportへ揃える。
- Pulseには実際のプロジェクト・Issue・クエスト・Check-inに対応する4つの短いカードを順次表示する。Voicesは原作の4場面と縦スクロールから横移動への変換を維持する。Frequencyは4件の匿名・抽象的な仮再生ログ。Thresholdの文字サイズと`joiN`は元のままにする。
- Community 3点、Passport 4点の画像を生成して差し替える。画像の出典と生成プロンプトを記録する。
- 元のライセンス文面・著作権表示を保持する。参照元を独自MITコードと表示しない。
- バックエンドのモック化と既存のデモ隔離を維持する。

## 公開

既存のVercel Git連携先`sangraal-demo-initiation`がこのブランチをProduction環境へデプロイしている。変更を同じブランチへpushし、Vercelのデプロイ完了を確認してURLを渡す。

今回のユーザー指示に従い、単体テスト・統合テスト・lint・独立した型チェック・ブラウザ操作テストは実行しない。公開に必要な生成処理と本番ビルド、デプロイ状態の確認だけを行う。
