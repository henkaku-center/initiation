## 決定

依頼者の指定した https://sangraal-demo-initiation.vercel.app/#home を下部コンテンツの基準とする。文字ヒーロー「henkaku → 変革 → 暗転」の後に、Community Pulse、VOICES / PODCASTの公式YouTube映像4場面と番組紹介、FREQUENCYの架空の再生履歴4件、参加入口を一続きの文書で表示する。

2026-09-12の通常アプリ接続で一旦外した映像とサンプル履歴を、削除前の `cca6e14^` の実装から復元する。この点は `2026-09-12-portal-app-integration.md` と `2026-09-12-frequency-listenbrainz.md` のトップページ表示方針を更新する。参考デモの模擬認証や状態ストア、ヒーローBGMは復元しない。

- 映像は公式YouTubeの埋め込み。元の一時停止状態から利用者の操作で無音プレビューを開始し、表示中の1本だけを再生する。埋め込み失敗時は公式サムネイルと動画リンクを残す。素材ファイル自体は収録しない。
- FREQUENCYのリスナー・アイコン・相対時刻は固定サンプルと明記し、再生操作で更新しない。ウォレット、Cookie、localStorage、DBへの視聴履歴の読み書きは追加しない。通常のトップページからListenBrainzへは問い合わせない。
- Community Pulseの実データ取得、現在の認証、Setup・Initiation等のルートは維持する。
- 既存のヒーロー待機時間（PC 1.06秒・820px以下1.71秒）、Shadow DOM内の取得失敗案内、Issue取得10秒と離脱時中断を保持する。旧ランキング文書の8秒タイムアウト付きアダプターも互換経路として保持・検証するが、サンプル表示には使用しない。
- Shadow DOMでは元のbodyの横はみ出し制御を `overflow-x:clip` に置き換え、本文内にスクロールコンテナを作らない。参考デモのiframeと同じく、ヘッダーを除いた高さで固定表示と場面移動を計算する。
