# 2026-09-09: デモのJavaScriptを必要な場面で読み込む

ユーザーから、公開サイトの初期読み込みを軽くするため、JavaScriptの遅延読み込みだけを実装するよう依頼された。

- Setup・Initiation・Passport・Communityの4画面を `next/dynamic` で分割し、既存の画面選択条件が成立した時に読み込む。ホームと共通のナビ・状態管理は初期バンドルに残す。
- YouTube IFrame APIとプレーヤーの生成は、動画セクションが近づいた時、または利用者が再開を押した時まで待つ。イントロ表示中・非表示タブ・親画面の停止中には開始しない。
- プレーヤーのポーリングも生成後に開始する。重複ロードを防ぎ、離脱とブラウザの戻る／進むによる復帰を扱う。
- 初期停止・無音・表示中の1本だけを再生する条件、画面構成、CSS、フォント、画像、URLの対応は維持する。

デモの入口を表示するための初期処理を減らす変更であり、MVP-1の会員・認証・申請処理には手を加えない。
