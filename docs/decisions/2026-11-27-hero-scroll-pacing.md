# 2026-11-27 ヒーロー終盤のスクロール速度を制限する

依頼者と相談し、「変革へ寄る → 暗転」をスクロールに応じて進めつつ、速い入力でも途中を飛ばさない方式を試す。参加入口までの連続した体験を保つため、最後のズーム区間の進行速度を制限する。

- 文字の組み立てに必要な既存の待機は維持する。組み立て後は入力に反応して動き、固定時間の追加待機は設けない。
- ヒーローのスクロール距離を最短約1.6秒で進む上限とする。遅い操作は入力量に比例する。
- 入力の蓄積は全距離の10%（上限速度で約160ms）までに制限する。逆操作では以前の入力を捨て、最初に戻る操作・離脱でも破棄する。
- ホイール、タッチ、スクロールキーを親ページとヒーローiframeの両方で扱う。暗転完了後は通常スクロールへ戻す。アンカー移動・スクロールバー・動きを減らす設定には介入しない。
- ズームと暗転を同じ進行値に同期し、二重の遅延を避ける。
