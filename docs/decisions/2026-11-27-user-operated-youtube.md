# 2026-11-27 Podcastを通常のYouTubeプレイヤーで再生する

依頼者の指定により、`2026-11-27-reference-gateway-content.md` の無音プレビュー方式を変更する。4つの映像枠と番組紹介・サンプル履歴の配置は維持し、各枠でYouTube標準の再生・停止・音量・シーク・全画面操作を使えるようにする。

- 「映像は一時停止中 · 音声なし」、SOUND OFF、無音プレビュー専用の再開ボタンを取り除く。通常時の独自ステータスは表示せず、実際の埋め込みエラーだけを案内する。
- 自動再生、強制ミュート、ランダムな開始秒、20秒ループ、スクロールによる自動再生は行わない。利用者が選んだ回を最初から操作して再生する。
- ある動画を再生したら、ほかの動画は停止して音の重なりを防ぐ。ページ離脱時はプレイヤーを破棄する。音量の値はアプリから変更しない。
- iframeを直接操作・キーボードフォーカス可能にする。YouTube APIが利用できない場合も、標準iframeの操作は残す。
- 公式YouTubeへの外部リンクを残す。FREQUENCYは引き続き固定サンプルで、実際の視聴履歴を収集しない。ヒーローBGM・認証・Setup導線は変更しない。
