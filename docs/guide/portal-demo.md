# ポータル体験デモ（提供終了）

PR #102のUI・参加体験は通常アプリに接続しました。別の模擬画面・デモ操作・デモ専用buildは廃止しています。現在の起動方法、認証・保存、準備中の機能、公開切替・ロールバックは[ポータルアプリ](./portal-app.md)を参照してください。

旧 `/demo#setup`・`/demo#journey`・`/demo#community`・`/demo#passport` は対応する通常URLへ移動します。以前のブラウザ内のデモ回答や模擬審査結果は読み込まず、サーバーデータへ移行しません。回答の保存と参加操作には実認証が必要です。

画面の演出、画像・音源・クレジットは通常アプリに残っています。経緯と検証方針は[模擬アプリ廃止の決定](../decisions/2026-09-12-retire-portal-demo.md)に記録しています。
