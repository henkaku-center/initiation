## 収録前に確認すること(音源に固有)

[ライセンスの決定](../../docs/decisions/2026-08-11-license.md) と CONTRIBUTING.md より、
音源は許諾の確認だけでは足りない。次がすべて確認できるまで収録しない。

- [x] CC BY 4.0 での利用・改変・再配布について、提供者から許諾を得た
      (制作者本人がこのリポジトリへ収録するため。inbound = outbound)
- [x] 帰属表示に使う名義を確認した(本名・ハンドル・匿名希望のいずれか) → `karawapo`
- [x] 許諾と名義を、後から確認できる形で記録した(Issue やスレッドへのリンク)
      → https://github.com/henkaku-center/initiation/issues/80
- [x] 作曲の権利は制作者本人が持つ。歌詞はなし(インストゥルメンタル)
- [x] その権利が JASRAC・NexTone などへ信託されていない(信託されている場合、**作った本人でも CC BY 4.0 で提供できないことがある**)
- [x] 既存曲のカバー・アレンジ・サンプリングを含んでいない(すべて本人の作曲・演奏)
- [x] 打ち込みのパターン(特にドラム)が、市販のMIDIループ集や音源の付属パターンではない
      (**MIDI ファイルそのものの再配布を禁じているライブラリがある。**
      このドラムは本人が打ち込んだもの)

以後の作品でいずれかに当てはまるものが出た場合は、収録せずに Issue で相談する。

## 原盤(録音)の権利について

`.mid` と `public/music/*.json` は**演奏データであって録音ではない**ため、原盤権は発生しない。
音源で鳴らして書き出した音声ファイルを収録する場合は、その時点で原盤が生まれるので、
**その音声を作った人と、使った音源ライブラリのライセンスを別途この表に記録する。**
